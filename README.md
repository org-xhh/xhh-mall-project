# xhh-mall-project

vue@3 + vite@5 + vue-router@4 + pinia@2 + element-plus@2 + axios + less + postcss + eslint + prettier

# 环境准备

| 环境         | 名称版本 |
| ------------ | -------- |
| **开发工具** | VSCode   |
| **运行环境** | Node 18+ |

# Usage

### npm run dev

本地启动

### npm run build:release

测试环境打包

### npm run build

正式环境打包

### npm run preview

打包后预览

### npm run lint

eslint 代码格式化

### npm run format

prettier 代码格式化

### npm run prepare

npm install 之后自动执行；npm publish 之前自动执行

### npm run postbuild

npm run build 后自动执行

### npm run eslint:rules

查看 eslint 所有校验规则
